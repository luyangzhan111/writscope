# 历史归档

历史文档用于追溯需求、配置、预算授权边界、开发接线和交接过程。它们保留各自时点，可能含已被后续步骤完成的待办；当前入口是 [文档导航](../README.md) 和 [项目状态](../project-status.md)。

| 分类 | 内容 |
| --- | --- |
| [规划](planning/README.md) | 初期审核、路线图、相关工作线索和诊断设计 |
| [预检与冻结](preflight/README.md) | 运行前范围、费用和一次性授权边界；旧许可不能复用 |
| [离线实现过程](implementation/README.md) | 组件接线、交互版本和模拟入口的开发记录 |
| [交接快照](handoffs/README.md) | 当时的工作树、迁移依赖和接续路线 |
| [公开发布](releases/README.md) | 本地候选整理与首次 GitHub 发布记录 |

实际结果和代表性失败在 [实验记录](../experiments/README.md)。本次分层保留全部 81 篇原有文档，其中 76 篇迁移至实验或归档目录；原始交接书不改，冻结规格及研究工件的原始哈希不变。移动的历史正文只调整文档链接，不追改结论、费用或授权。

[迁移清单](migration-map.json) 列出旧路径、新路径、兼容入口和原始提交。需要查看原始路径下的完整版本时，可使用其中记录的 Git 提交。
