# M3i：任务背景原文账本离线子步

日期：2026-10-22。性质：离线工程验收，**不是模型提取或方法效果证据**。

## 本步范围

新增 [版本化账本](../../../scripts/m3i_task_context.py)。它按决策点前的可信事件顺序消费一个批次；同一用户事件可以提交多条任务背景引文。每条 `requirement` 保留原文、不作语义改写，附可由程序定位的唯一精确引文、稳定 ID 和公开验证引用。工具、助手和系统事件只能提交空批次；错误引文、私有/不存在的验证引用、乱序和重复批次在写入前拒绝。每批次保存前后哈希，重放逐条核对。

三条首例历史的共同前缀用于定向测试：e001 的页面目标及本地映射、e004 的少改动与不新增请求分别可在同一事件中保留两条；e002/e003 工具反馈以空批次推进。引文由测试显式提供，**没有模型自动抽取**，也没有把 e005 的授权句子伪装成任务背景。账本没有任何授权判定接口，不能改变 M3f 的授权范围判断。

## 验证与边界

- `.venv\Scripts\python.exe -m pytest -q tests/test_m3i_task_context.py`：6 passed；Windows `.pytest_cache` 写入有已知权限警告，测试本身通过。
- 测试覆盖三历史一致前缀、同事件多引文、可信角色、错误/私有引用的原子拒绝、乱序/重复以及篡改后回放拒绝。
- 本步没有新增真实模型请求，真实 token 与费用不适用；旧 M3c–M3h 运行和源码哈希未改。
