# M3k：截止点前历史回查离线子步

日期：2026-10-23。性质：离线工程验收；回查请求由测试或人工提供，**不是模型自主回查或方法成绩**。

## 已实现

[版本化回查入口](../../../scripts/m3k_history_lookup.py)仅从公开输入的可信原始事件建立索引，并在 `decision_point` 截断。请求只接受事件 ID 列表，不接受路径、任意文件名或搜索表达式；返回完整原文、原角色和可信来源。一次请求中有未来或未知事件 ID 时，整体拒绝、不返回部分事件。请求次数和单次事件数有显式上限；超限及拒绝尝试也计入调用记录。

每次记录请求、状态、拒绝原因、返回事件、耗时与请求/响应哈希。离线入口保存 JSONL 日志及包含公开包哈希、可见历史哈希、政策、尝试数和日志哈希的运行摘要，并可无模型重放核验。此入口没有把工具消息提升为用户授权，也没有读取评分标签或参考状态。

## 验证与边界

`tests/test_m3k_history_lookup.py` 的 5 项定向测试通过：决策时点后的合成事件不能泄漏，混合合法/越界 ID 整体拒绝，工具原角色保留，次数与条数上限生效，保存记录可回放且篡改被拒绝，错误决策点被拒绝。

本步新增真实模型请求 0 次。回查的本地耗时已记录；模型选择回查的请求、后续承载回查结果的 token 与费用**尚未发生且未实现计费**，不能填为零或与基线比较。M3i 任务背景、M3j 多转换和本回查入口已在 [M3l](m3l-offline-trace.md) 组成一条人工计划驱动的离线轨迹；终点模型复核仍待实现。
