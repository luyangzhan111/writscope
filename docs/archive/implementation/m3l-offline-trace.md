# M3l：任务背景、多转换与回查同轨离线集成

日期：2026-10-23。性质：离线机制验收，输入是手工计划及脚本响应，**不是模型方法成绩**。

## 运行顺序与失败边界

[版本化运行器](../../../scripts/m3l_offline_trace.py)逐事件执行：先按当前事件截断历史并处理回查，再写 M3i 任务背景批次，最后解析并提交 M3j 状态转换批次。回查额度跨事件累计；响应只含模型将来可提交的条目，case、事件、序号与调用 ID 由运行器补齐。任一回查拒绝、任务背景错误、响应无效或状态批次拒绝都停止后续事件；不生成终点诊断。

运行保存 `plan.json`、逐步 `trace.json`、`state.json`、`task_context.json` 和 `run.json`；完整成功时另存 `assessment.json`，**仅为确定性结构范围诊断，不是终点模型复核**。摘要冻结公开输入、计划、配置、组件源码、环境及工件哈希，记录回查次数/耗时、失败与零次实际模型调用；验证器用保存的计划重建轨迹并核对内容，耗时只按保存的测量值校核汇总。提取及终点模型 token/账单仍未知，不以本离线运行的零调用数代替未来费用。
