## 已实现

[独立运行器](../../../scripts/m3m_final_review.py)先完整验证 M3l 来源轨迹。仅当所有事件全部接受、状态与任务背景到达决策点时，才从已核验公开包构造 `incremental_review` 请求。请求包含与完整上下文基线相同的 `review_input`、公开工件及注册表，另外附方法生成的 `current_state`、`task_context` 和已经执行的历史回查记录；基础公开证据哈希与基线一致。请求使用版本化 [终点提示词](../../../prompts/incremental_final_review_v1.md) 和 `source_quote_v1` 输出结构。未完成轨迹只记录 `no_final_review`，无请求与响应。

可选脚本响应由调用者本地提供，不使用 provider。程序复用严格引文、三轴和逐影响契约，再检查响应引用的状态条目 ID、类型及原文来源确实存在于当前状态；错误响应原样保存，不产生 `result.json`。`run.json` 冻结来源轨迹、公开包、请求、源码和工件哈希；验证器从原始轨迹重新构造请求、重验响应并比对结果。结构通过不证明模型语义正确。
