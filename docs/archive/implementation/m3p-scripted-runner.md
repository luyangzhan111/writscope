# M3p：脚本提供商同轨运行器离线验收

日期：2026-10-24。执行类型：**离线脚本提供商轨迹**。实际外部模型调用 0 次，没有新付费授权、真实模型状态或方法比较成绩。

## 已接通的路径

[版本化运行器](../../../scripts/m3p_scripted_runner.py)仅创建 `ScriptedMock`，不读取密钥或构造网络提供商。每个事件先依据 M3o 契约生成带可信历史前缀、先前状态和任务背景的请求；脚本响应只能请求 M3k 回查或提交 M3i 任务背景与 M3j 原子状态批次。回查成功后另计一次 M3n `lookup_continuation` 尝试，再送入可信原文。回查耗时保存在审计轨迹，但进入后续请求的记录固定为 `elapsed_ms=0`，使请求字节、预算预留和回放稳定。

每次脚本 provider 尝试先按 DeepSeek 线格式计算请求字节并占用 M3n **模拟价格**预留，保存请求、原始响应、模拟 token 用量、停止原因和账本。五个事件接受后才生成显式模型配置的终点请求；脚本终点响应通过 M3m 的 `source_quote_v1`、三轴和当前状态来源校验。任务背景先在副本中预检，状态批次接受后才一起提交；批次拒绝时任务背景不部分落账。失败轨迹没有有效终点 `ReviewResult`。
