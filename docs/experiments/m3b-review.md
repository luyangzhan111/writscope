# M3b 增量方法离线接线验收

日期：2026-10-21。状态：**逐事件请求、脚本响应、状态更新、终点范围判断和可回放运行记录已离线接通；真实模型提取与方法比较未运行。** 本步承接 [M3a 内核](m3a-review.md)，只推进 [S3](../implementation-plan.md) 的无网络接线部分。

## 交付边界

- [增量运行器](../../src/writscope/m3b.py) 使用现有 `ModelRequest` / `ScriptedMock` 接口。每个事件生成一份请求，包含到该事件为止的原始历史、同一公开工件白名单和此前重建的状态；最终基础证据哈希与两种完整上下文基线一致。运行器而非响应文本提供可信 case、事件 ID、顺序和提取配置哈希。
- [提取提示词](../../prompts/incremental_extract.md)和严格的 `ExtractionPayload` 只让响应提交操作、当前事件唯一原文、目标 ID 及结构化草稿。`StateEngine` 再校验角色、来源、引用、范围及生命周期。无效 JSON、伪造工具授权或状态转换拒绝会保留请求、原始响应及错误，停止该次轨迹，不伪造最终判断。
- 终点仅对完整且每步成功的状态调用 M3a 的逐影响匹配。公开影响事实、授权范围和组合决定分别保存。CLI 强制脚本提供商，不接入 DeepSeek、不读取 API 密钥；脚本可包含人为正确或错误的输出，**其结果只验证管线，不能计入方法成绩**。
- 运行目录保存 prompt、已解析脚本、每步请求/响应/调用记录、转换 JSONL、状态、完整运行才有的 assessment、工件哈希、代码树与锁文件哈希。费用中实际模型调用为 0，真实提取 token、费用和账单为 `null/unknown`；模拟用量、提供商等待、管线尝试、状态更新、匹配和总墙钟耗时分字段保存，不把重叠时间相加。
