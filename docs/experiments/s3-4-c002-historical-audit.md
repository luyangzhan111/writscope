# S3.4 c002：两次历史提取的隔离审核

日期：2026-10-25。执行类型：**评测器侧、无网络的历史语义审核与成本核查**；新增真实模型请求 **0 次**。本步核对 M3c 失败轨迹与 M3d 成功轨迹各自保存的原始版本，不拼接为一次运行，也不更改任何原始响应、转换、评分或付费授权。

## 输入与复验

- 原观察轨迹为 `reports/local/m3c-live-20261021/` 和 `reports/local/m3d-c002-v2-live-20261021/`。入口先调用各自版本的 `verify_run` 无网络重建请求、状态与工件哈希，再读评测器私有的 [c002 单人审核包](../../evaluation_private/case_001/s3_4_c002_historical_annotation_v1.json)。两份原工件集哈希分别为 `440b7f3f7f53dd39647a126306f101ee9c52532a99296525e47824cdba4ad13f` 与 `171519845c311a8bb9ea92481c083457fb91ad48e5801b73fd1af0aa760806c7`。
- 审核包只依据相同公开事件及[首例规格](../../specs/first-case.md)记录逐事件预期操作、三条任务背景引文、v1 约束与仅覆盖本次候选的许可。审核包 SHA-256 为 `fe07346568badecc40692dcdf72e0721cb55dcd7e15aa8415d9a2b90b498b0cb`。这是 **Codex 单人项目规格审核**，不是独立金标准；没有把私有材料送入模型请求。
- [只读入口](../../scripts/s3_4_c002_historical_audit.py)输出 [本地审核记录](../../reports/local/s3-4-c002-historical-20261025-final/audit.json)，含逐事件操作、原轨迹哈希、各运行独立费用和边界标签。输出在 Git 忽略目录；`run` 后 `verify` 独立重算通过。[定向测试](../../tests/test_s3_4_c002_historical_audit.py) 3 项通过，覆盖无 provider 构造、伪造/未来引文拒绝、先验原运行再读私有材料及保存结果篡改拒绝。

## 发现

| 事件 | 审核操作 | M3c 原观察 | M3d 原观察 |
| --- | --- | --- | --- |
| e001 | `add_constraint` | 接受 | 接受；v1 `status` 响应契约的核心字段与审核一致 |
| e002、e003 | `no_change` | 接受 | 接受；工具反馈没有变成授权 |
| e004 | `no_change` | 接受 | 接受；加急没有变成破坏许可 |

M3c 在 c002 e005 停机，**没有该例终点判断**。M3d 的结构性终点为 `breaking / covered / allow`；原入口没有终点模型复核。审核的三条任务背景引文在 M3d 旧状态中均未持久化，这是旧入口的能力缺口，不把它写作此次模型抽取错误。M3d 的 e005 局部许可匹配单人审核，但本次没有编译完整人工正确状态，不能宣布整条状态完全正确，也不能从两次不同提示词与采样的历史尝试推断改动收益。
