# M2b 引文契约离线修订验收

日期：2026-10-20。状态：**代码、提示词、数据契约和离线回归已完成；新版没有真实模型运行或付费请求。** 触发问题和首次六任务的正式负结果见 [M2b 首次真实接通](m2b-real-review.md)。

两种完整上下文方法现在共同使用 `source_quote_v1`：请求 schema 只让模型在每个来源引用中提交 `event_id` 与精确 `quote`。运行器在该事件的可见原文中查找；只在引文出现恰好一次时派生 `[start,end)` 并保存为原有 `ReviewResult`。缺失或重复引文、超出决策时点的事件、非用户授权来源均拒绝。位置转换只解决结构问题，不替模型判断授权范围，也不使用私有标签推断答案。正式真实运行路径拒绝模型自报位置；历史 M2a 脚本和首次真实运行的旧 `source_span_v0` 记录保持原样，旧跨度仍按严格原文切片规则校验。两方法原始公开证据与模型配置继续一致，只有各自方法提示词不同。

在仓库根目录可离线复现：

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider --basetemp .work/pytest-quote-new
.\.venv\Scripts\python.exe -m writscope.m2b preflight --output reports/local/m2b-quote-preflight-new
uv --cache-dir .work/uv-cache lock --check --offline
```

每次预检输出目录必须事先不存在。新版是否能让真实模型稳定提交合法引文尚未测；若要验证，应先确定新的开发运行范围、凭据与累计费用规则，单独保存预检、响应和评分。此修订没有提供方法准确率、成本优势或泛化结论。M3 增量授权状态组件仍是后续阶段。
