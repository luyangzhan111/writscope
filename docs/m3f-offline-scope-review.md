# M3f：跨版本约束引用的离线范围校验

日期：2026-10-22。执行类型：**版本化离线机制诊断**，新增真实模型调用 **0 次**。依据 [M3e c003 原始诊断](m3e-real-review.md)中已保存的错误状态提案；旧 M3c、M3d、M3e 运行及评分不改写，不用新规则追溯改分。

## 规则与实现位置

新增独立 [scope_ref_v2_offline](../scripts/m3f_scope_policy.py) 策略，源码 SHA-256 `05e4c2c0245c1e8c26cae6c1a7dcf03a4b2a2f86dd4fa10e66a89efb77bb57de`。它在原 M3a 状态内核提交授权前增加以下检查：

1. 授权 `subjects[].field` 必须与 `change_details.old_field` 一致；替换操作的主体定位被替换字段。
2. 每个 `constraint_refs` 须指向活跃约束，且该约束与授权至少有一个**完全相同的 Subject**；一个宽约束含多主体时，仍允许仅对其中一个主体建立局部例外。
3. 没有相应已有约束的未来版本授权可以使用空 `constraint_refs` 保留为活跃授权，不因此扩大到旧版本。

策略位于 `scripts/`，未修改 `src/writscope/state.py`、历史提示词或真实运行入口；因此它目前**不是 M3c/M3d/M3e 当时生效的校验**。来源、时点、操作类型、引文和既有范围判定仍由原内核处理。新策略只检查结构上可确定的关系，不能证明模型理解了自然语言，也不能把真实模型响应自动修正为其他提案。
