## 目标与验收范围

补齐三历史×三方法九个“案例×方法”轨迹，并在三条增量轨迹中观察模型是否自主选择历史回查。以 R=1、同基础模型、同公开原始证据、同影响工具和原两种完整上下文提示词执行。所有轨迹从空状态开始，不拼接此前轮次。增量提示词单独升级为 interaction v3，专门明确“客户端本地映射”不代表服务端 API 字段变更：保留服务端 status 约束，将用户提出的本地映射记作任务背景；只有明确授权的服务端变化才提出服务端授权。该提示词不包含案例答案。

外部审核者当前不可获得，故本轮最多支持**作者审核的 S3 开发验收**：仍用项目作者草稿作参考，并明确其非独立金标准。不会据此签收独立研究验证或宣称方法普遍优劣。模型预测允许错误；报告逐行保留无效输出、错误、失败、未运行、三轴分子/分母、回查状态和全程费用。九轨覆盖只有在九项均尝试且无轮级预算/完整性停机时才算覆盖完成。至少一条自然触发、成功回查并继续到终点，才算本次取得自主回查证据；未触发时如实记 `not_exercised`，本轮不自动重跑，开发验收仍缺此项。

## 运行规则

- 模型：DeepSeek `deepseek-flash`，temperature 0，max output 4096。官方价格页当前列示 `deepseek-flash` 对应 DeepSeek-V4.1-Flash-1017；实际 served model 留存响应记录。
- 九轨固定轮转，R=1；三条 incremental 每条最多 8 次（5 次提取、最多 2 次自主回查续答、1 次终点复核），每条基线最多 1 次。全轮最多 30 次，单并发，每次 90 秒、无重试。
- 输出/解析/提取/状态拒绝或 provider 错误停止当前轨迹；其他轨迹继续，以补齐覆盖并保留轨迹级失败。达到全轮预算、请求/记录哈希不一致或安全/完整性错误时，停止全轮，后续行保留 `not_run`。一次授权仅执行一次，不续跑、不自动重试。
- 回查仅可由模型按原提示词自主发出；可读截止点前历史，不新增人工提示或强制工具调用。保存 lookup intent、批准/拒绝、返回原文、续答请求、用量与最终状态。脚本 lookup 和提示诱导控制不计入自主证据。
- 保留前一轮 c001 失败记录。v3 是新提示词、新 scope、新计划哈希；结果单独报告，不与前轮拼分或作改进排名。两基线继续用原提示词与相同输入。
