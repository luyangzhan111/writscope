# R4：独立轨迹验证和正式评测候选

在 `D:\AI-Project\writscope` 完成剩余计划 R4 的代码与离线验证。先读 AGENTS.md、`docs/s4-remaining-plan-review-20261030.md`、R2/R3 记录契约，以及 s4_metric_core、s4_metrics_pipeline_offline、s4_shared_metrics_offline、s4_citation_quality 和 s4_accounting_core。

实现可直接消费统一运行记录的验证器与评测器。现有与旧 scripted_run 逐项相等的检查只保留兼容诊断；新入口必须能独立验证真实候选记录。先验证任务唯一性和完整分母、计划/公开包/源码、实际请求与响应、来源/角色/截止点、回查、状态转换、终点与账本，再读取评测器参考、配对和裁决表。验证失败前不得读取参考；伪造真实标记和整体来源不明时拒绝正式评分，不能靠换一个 execution_kind 放行。

输出三轴及全部轴、参考 breaking 非争议授权主分母、合法/未授权/歧义范围、相同 repeat 成对、无有效输出、误放行/误拦截、原始分子分母及完整成本。失败/未运行保留，不改成 revise。增量合法终点与状态冲突的主失败及预定义诊断分别保存。引用合法性与语义支持分开；无真实语义审核则记未评估。费用、token、账单、时间的未知项保留 unknown。

用混合正确/错误/缺失的独立合成样例验证指标，覆盖重复/遗漏任务、未来引用、工具冒充用户、无效终点、冲突、账本篡改和假真实身份。模拟只用于算法验证，不在项目结果中发布模型准确率。交付独立评测入口、版本化报告契约、定向测试和真实性证明的实际边界；未解决的验证能力明确列为缺口。

不读真实密钥、不调用模型、不外发、不付费，不修改旧标签或历史评分。项目内草稿参考不能改称独立金标准。
