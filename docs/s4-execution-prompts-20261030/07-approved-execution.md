# R7：仅在具体新计划实际获批后真实执行

本提示词本身不授权任何模型请求、费用、凭据读取或材料外发。仅当用户在实际会话中另行明确批准 R6 对应的具体计划、金额上限、最多尝试数、服务商与发送范围时，才进入下述执行。批准缺失或范围不符时，完成剩余离线检查并报告缺失项；不得用此模板、测试收据或旧 S3 批准替代。

在 `D:\AI-Project\writscope` 先读 AGENTS.md、`docs/s4-remaining-plan-review-20261030.md`、R6 精确冻结计划和实际批准证据。复核数据/参考/提示词/schema/源码/模型、官方新鲜价格、公共输入白名单、计划分母和一次性启动；任何会改变已批准费用、材料或实验意义的差异先重新形成候选并取得相应批准。通过可信检查之后才能读取凭据。

只执行本次获批范围，单并发、按冻结重试规则，发送前持久预留。记录每次请求与原始响应/错误、未知用量、回查、状态更新、终点及成本。普通错误和全轮故障按预定规则停止，额度不足不补跑，未触发回查不强制补齐。保存全部负结果、未运行任务与分母，成功与否不改变门槛。四例试跑的授权不能延伸成正式 270 轨主比较。

执行后先保存再离线回放、验证及独立评分，分别报告影响/授权/决策、缺失、歧义、成对、误放行/误拦截、引用检查和完整成本；账单未知明确保留。报告所有失败和实际服务版本，不把项目内参考改称独立验证，也不外推未见家族。交付本轮运行收据、实际尝试/费用记录、可重建报告与结论边界。本轮批准用完即结束，任何补跑都需要新的具体计划与批准。
