## 如何重建

在项目根目录、使用项目虚拟环境运行以下命令；输出目录必须不存在，且其父目录需已存在：

```powershell
.\.venv\Scripts\python.exe -m scripts.s4_p1 --output .work\s4-p1-demo
```

入口只运行清单绑定的固定可信代码、固定候选补丁和私有兼容补丁；不接受任意待执行代码。每个 `bundles/<案例 ID>/` 是单独的公开输入包，兼容修复和完整验证报告在同级 `private_validation/`，只供评测器使用。**只能把单个公开包作为方法可见根目录，不得提供输出总目录。** 当前工具执行关闭；这套目录隔离不是操作系统沙箱，也不允许向方法开放任意 shell/Python。

公开包沿用已有 `ReviewInput` 和 `ImpactEvidence` 结构，含可信导入的截止点事件、原始快照、固定补丁、公开契约、公开检查及同一份已执行影响证据；不含私有参考、兼容补丁、私有验证记录或未来事件。材料清单按路径和哈希验证；补丁只应用于隔离副本的 `app.py` 或 `client.py`，使用精确上下文，不支持模糊匹配。清单哈希绑定保证本地材料一致，不是抵御能同时修改项目代码的攻击者的签名。
