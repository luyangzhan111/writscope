# S4 R2 单账本离线入口：实现进度与限制

2026-10-30。新增[统一离线入口](../scripts/s4_unified_offline.py)和[单 SQLite 账本](../scripts/s4_unified_journal.py)，复用既有 `s4_candidate_cost_mock_runner.execute` 的三方法、回查与状态逻辑，没有再复制完整运行器。旧的双账本入口和历史证据未修改；本入口是其后续候选，并不自动迁移旧记录。

统一入口保存完整任务计划及每个 repeat 的轨迹，账本按四元任务身份绑定每次请求字节、虚拟金额预留、状态、起止时间、模拟 HTTP 响应原始字节/错误、finish reason、结构验证结果与 unknown 用量。回查续答有单独标记。固定 MockTransport 只在 `dispatch_started` 后生成合成响应。该路径没有可执行的真实传输分支；费用单位和价格都是虚拟值。

账本状态：`reserved → dispatch_started → received → completed/failed`；超时可从 `dispatch_started → failed`，保留 unknown 响应；进程中断留下 `reserved`、`dispatch_started` 或 `received` 未决状态，禁止继续预留。预算不足在预留前拒绝，未发送的不计调用；写入失败及账本完整性故障停止全轮。失败后不释放预留，不支持自动恢复。

最终版本相关测试 **12 项通过**，含三方法 R=3、回查续答、预算不足、截断、不可解析原始响应、内容大小、模拟超时、响应及验证记录写入失败、未决状态和篡改；测试不是模型成绩。另有[s4_027 单例三方法演练](../evaluation_private/s4_review/s4-unified-r2-check-v3.json)：3 条轨迹、8 次模拟尝试，保存后重开并核对；虚拟预留不是人民币。此前 v1/v2 是源码调整前的中间记录，保留但不作为最终证明。完整 270 轨验收留待 R5。

## 尚未满足的 R2 条件

- 本入口仍复用脚本运行器，轨迹的回查、状态转换和终点仅在每个 repeat 完成后整体持久化。进程在 repeat 中途退出时，账本仍保留请求与未决状态，但不能完整恢复已完成任务的转换或终点。当前验证器检查计划、账本与轨迹绑定，不重建状态机，也不证明真实来源。
- 模拟传输与真实 provider 接口尚未统一；真实响应、服务商用量、缓存/reasoning token、实际账单、提供商错误详情仍未接入。内容字节限制不是对整个 HTTP 响应流的预读取上限。
- 已记录模拟传输耗时，状态更新、查回、独立验证和共享证据制作的本地耗时尚未逐项采集；成本报告尚未接入统一契约。字节代理不是实际 token 上界，虚拟价格不是实际报价，本地预留不是提供商硬账单上限。
- 凭据前授权、一次性启动、真实网络传输、正式评分和冻结仍待后续工作；用户逐例语义未签收，独立审核按用户决定跳过且记未执行。完成本步不授权费用或材料外发。

因此本次交付为 **R2 部分完成**：单账本和离线接线已有小范围证据，不能声称 R2 所有运行记录、完整成本及中断恢复要求已经完成。新增真实模型请求 0，未读取实际密钥或发送材料。
