# S4 R3 模拟计划与保存记录核对

2026-10-30。R3 继续保持真实发送关闭，未读取实际凭据、未联网调用模型、未外发或产生费用。

## 本次补充

[模拟提案接口](../scripts/s4_r3_proposal_offline_v1.py)将检查点计划、模拟模型配置、合成价格与过期时间、虚拟上限、最大尝试数、单并发无重试和公开材料范围组合为 `draft_unapproved` 结构。价格必须与共享虚拟预算规则一致，评测器参考明确排除；虚拟单位不是人民币或实际报价。结构校验要求与调用方提供的预期提案哈希一致，并拒绝过期或不一致的内容。模拟测试所用的预期哈希不是实际授权凭据；此校验本身不重新读取公开包验证磁盘内容，也不将自报内容视为批准；运行闸门另行校验其受绑定计划。只能接受 `mock.invalid` 和合成模型，该接口不接实际凭据或模型传输。

[保存记录一致性核对](../scripts/s4_r3_checkpoint_audit_v1.py)以 SQLite 只读方式检查已完成的模拟轨迹：重新绑定计划及源码，核对完整任务分母、任务次序、各次请求字节与续答标记、响应内容、检查点顺序、回查、状态转换、评估和终点与逐轨记录的一致性。对缺失或篡改拒绝，不更改运行记录。只支持全部完成的模拟结果；失败或中断仍用原只读检查查看未决状态，不能宣称已经通过此核对。该核对不重放状态机、不证明真实来源、也不计算方法成绩。

新增测试：模拟提案、记录一致性和两个独立进程竞争新入口的一次性 claim 合计 **17 项通过**。此前的单例三方法含回查工件亦经新核对通过（3 轨、9 次模拟尝试、26 条检查点），不是新增真实请求。提案、轨迹和 hash 都不能替代实际用户授权。

## 仍需处理

真实计划需要另行确定模型、收件方、真实价格来源及有效期和逐项材料范围，并实现与可信实际用户批准证据关联的核验接口；当前没有可验证实际批准的接入，真实入口无条件拒绝。正式数据仍须逐例处理并冻结。R4 独立重建、失败/中断轨迹的正式评测核验、R5 全批联合离线验收、缺失的本地耗时和真正账单/用量仍未完成。即使之后离线验收通过，也不自动获得付费或外发授权。独立审核仍为 `not_performed_skipped_by_user`。
