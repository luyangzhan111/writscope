# R4 独立轨迹验证与评测器离线接线

2026-11-02。R4 本次离线实施完成：从实际保存的请求/响应和检查点重建轨迹，再读取评测器侧参考与处理口径。状态为 `offline_evaluator_acceptance_passed_live_disabled`。这不是实际独立人工审核、数据冻结、模型效果比较或真实执行批准。

实现入口：[评测器](../scripts/s4_r4_evaluator.py)、[响应驱动验证器](../scripts/s4_r4_replay.py)；接口见 [R4 契约 v1](../specs/s4-r4-evaluation-v1.md)。机器状态、测试与工件哈希见[验收清单](../evaluation_private/s4_review/r4-offline-acceptance-20261102.json)。

## 已实现

- 从公共包和空状态逐步重建完整请求字节、历史回查与续答、状态转换、终点评估；核对角色、截止点、引用、原子状态、局部范围、持久化顺序、预算和全部计划任务。复用公共内核，不调用旧执行器或解析 Script 来重跑预设答案。
- 轨迹验证通过后才打开固定版本的私有 reference、audit、disposition、method-policy 和负责人有限决定。标签、配对和参考状态不会回传给方法。
- 原始三轴、全部轴、参考 breaking 授权主分母、歧义单列、相同 repeat 配对、误放行/误拦截和缺失全部接入既有指标内核。报告仅含明确标识的合成诊断计数，`accuracy` 和 `model_metrics` 始终为空。
- 增量终点合法但与维护状态冲突时，主结果失败且无有效输出；另存原始终点三轴、冲突轴与响应哈希作诊断。引用结构合法与语义支持分开，后者仍为 `not_evaluated`。
- 每轨、每方法/轨道和全轮成本统一核对；包含失败、回查续答、状态更新和本地验证。unknown 不转成零，未发送预留不增加发送次数，中断不释放预留。
- 未完成或持久化失败仅复验已保存前缀，保留完整清单，既不读取参考也不计算指标。只有预留的中断映射为 not_run，已发送或发送不明映射为 failed；这些是评测映射，不是自动恢复执行。

## 版本核对发现

R3 原小切片 `fixtures/s4_candidate/s4_027` 与 P3 审核记录绑定的整个公开包哈希不同。R4 因而明确拒绝直接给旧小切片套用 P3 同编号标签；旧切片仍可独立复验。此次接线测试从已保存的 P3 公开影响证据恢复少量对应原版包，并验证与原审核哈希完全一致，没有运行候选代码或重做影响实验。

R3 原执行器有单轨本地次数保护：触及该保护后，下一个任务可能只写入一次未发送的共享预算拒绝。验证器保留这个已绑定版本的实际行为，不把无发送的拒绝计成调用，也不允许预算停止后的新发送。未为此改写 R3 或历史证据。

测试包含：禁止调用旧执行器/Script、合法响应与原脚本不同仍能复验、重复/缺失任务、假真实标记、请求/响应篡改、重算链哈希后的状态和回查篡改、重复账本头、错误 finish/用量/时序、未来事件引用及回查、工具冒充授权、终点冲突、超时、截断、超大响应、次数不足和持久化失败。独立混合正确/错误/缺失的 toy 样例核对原始分子分母；没有把合成输出作为模型成绩。

这里重复 2 次只用于小范围配对接线测试，不变更正式候选 R=3。固定脚本由公共材料生成，不从作者参考复制答案。归档中测试控制源和 claim 明确是合成数据；原测试路径保留，不伪装成新的真实批准。旧 R3 的 **47 个证据文件与 4 个绑定源码/契约文件**另经哈希核对未变。

可以只读复验归档切片；输出使用尚不存在的新文件名：

```powershell
.\.venv\Scripts\python.exe -m scripts.s4_r4_evaluator evaluate --run reports/local/s4-r4-accepted-20261102/small_paired/run --bundle-root reports/local/s4-r4-accepted-20261102/small_paired/public --scripts reports/local/s4-r4-accepted-20261102/small_paired/scripts.json --output reports/local/s4-r4-rechecked.json
```

`verify` 子命令只核对公开执行证据，完全不读评测参考；`evaluate` 在验证后接参考。`--scripts` 只校验原计划文件哈希，不用其中的预期响应判断轨迹对错。

## 后续与边界

下一步是 **R5 同版本全批离线验收与交付恢复**；本步没有运行 30 例 × 三方法 × R=3 全批。R6 仍需正式数据/参数/价格冻结，真实执行前仍需生产级来源证明、可信批准来源适配和对精确新计划的费用及外发批准。

当前验证器支持 R3 v2 合成记录的独立结构/状态复验，尚不接受真实或未知来源记录评分。哈希和完整一致的记录不能证明实际调用过 provider；不能改一个 execution_kind 就放行。内核与运行器共用，不构成独立实现或独立人工语义评判；没有新增操作系统沙箱、任意执行工具或自动续跑。R3 没有独立的验证完成时间戳，丢失工作量及共享证据制作耗时仍 unknown。

参考保持项目内非盲 provisional；四项有限负责人确认不扩写成 30 例逐例签收，独立审核仍为 `not_performed_skipped_by_user`。实际密钥读取、真实模型请求、材料外发、新增费用和 GitHub 更新均为 **0**。
