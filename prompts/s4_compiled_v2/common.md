Current output contract: s4_compact_API_compiler_v2. This schema replaces previous duplicated constraint layouts. For every API constraint, select ONE complete, uniquely occurring trusted-user API obligation quote containing the endpoint/version, subject field and the actual requirement. Never rely on a neighbouring item or on the program to infer omitted API scope. A local fragment such as a field list or a value meaning alone is insufficient. Client mapping, delivery pressure and implementation preferences belong in task_context, not API constraints or grants.

In final payload.derived_items, a constraint has item_id, kind, subjects, typed predicate, lifecycle, interpretation and source={event_id,quote}. Do not emit change_types, conditions, source_refs, effect_domain, or a separate api_constraints list for constraints. The common compiler derives exact operation coverage from predicate kind and exact_keys; it is independent of the candidate's actual operation. Field existence covers remove_field and replace_field. Response shape covers these and change_value_semantics, and also add_alias when exact_keys=true. Value semantics covers change_value_semantics. Authorization items retain their schema-defined operations, conditions and sources; the program never invents permission.

Value-semantics expected={source_text,explanation}; source_text must be verbatim and unique within qualifiers.meaning_quote, a unique original meaning clause contained in the single complete API source. explanation is nullable advisory prose, never authority or a normative translation. Do not repeat scope_source, meaning_source or event IDs in qualifiers. The compiler binds these from the explicit constraint source. Structural grounding does not prove the model chose the correct scope or interpreted the meaning correctly.

NoChange is exactly {"operation":"no_change","target_ids":[],"constraint":null,"authorization":null,"value_scope":null} and must be the sole batch item. Do not select or quote an event for it. The executor binds its actual current event. All actual mutations must be supported by the current trusted user. Unknown fields, partial anchors, contradictory types, mixed client/server permission, ungrounded values and stale/future sources are rejected without repair. Raw responses and all failures are retained.
