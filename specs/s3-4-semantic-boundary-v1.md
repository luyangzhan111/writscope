# S3.4 语义判读与生命周期边界契约 v1

日期：2026-10-25。评测器私有的补充审核入口为 [semantic_boundary_audit_v1](../scripts/s3_4_semantic_boundary_audit.py)。它先重验两份已保存的 v2 状态诊断，再读取新的私有审核包和合成边界材料；不修改 v2 投影规则、原提取响应或模型契约。

## predicate 判读

`s3_4_predicate_review_v1` 绑定首例规格哈希、来源事件和精确引文、两例 v2 审核包哈希、观察/人工 predicate 的规范哈希、独立预期声明、审核者及判读理由。结论 `equivalent_on_reviewed_claims` 只适用于绑定的两份观察 predicate 和共同人工 predicate。

投影仅识别三种明确审核过的结构：`nested_http_v1`、`flat_canonical_v1`、`flat_type_alias_v1`。三者逐字段表示 HTTP 状态、精确响应体、字段类型、禁止额外字段和账户启用含义。字段全集必须吻合该布局；缺失含义、额外条件、冲突的精确键、未知布局或不一致类型均拒绝 `unsupported_semantic_projection`。改变 HTTP 状态、字段值或含义会保留为声明差异，不会被当成别名吞掉。

别名解释只由这批原文及单人审核记录支持，不是任意自然语言或自由 JSON 的通用语义归一化。生成声明必须同时等于观察投影、人工投影和独立预期；任一不符停止。v2 原报告中的表示差异标签作为历史快照保留，新的判读另立文件，不回写评分或把结论外推到 c003。

## 合成边界

`s3_4_lifecycle_boundaries_v1` 绑定 c002 v2 审核包哈希，独立保存六个中性分支 ID、每条扩展事件的可信角色/原文/序号、操作/目标、草稿模板及手写预期。它在评测器中复制公开前缀并从空状态重建，使用独立的 `b001`–`b006` 实例身份；不向任何原运行追加事件，不计为新增独立评测样本。

扩展操作在已有 M3j/M3f 引擎上运行。用户角色建立 `authority_level=user`，工具角色建立 `none`，不采信正文自称的角色。草稿模板只来自已审核的 c002 人工批次，不读取模型输出。预期另行记录以下内容：

- 每项约束/授权生命周期、授权歧义、更新来源及替代边；
- 历史例外数量，以及其授权 lifecycle 仍 active 的 ID 集合；该集合不等于对当前约束有效覆盖，覆盖另由范围检查判断；
- 接受时的确定性三轴；拒绝时该字段必须为 null，且后续计划事件不尝试；
- v2 对完整状态的投影应明确支持或拒绝。生命周期状态仍须报 `alignment_unsupported`，不得删去历史字段来凑成 active 图。

每个实际前缀与独立预期一致后继续；首个拒绝停止分支，所有批次日志另行确定性重放。没有 provider 调用、终点模型复核或方法评分。

## 输出

`reports/local/` 下一个新目录只写评测器可读的 `audit.json`，包含原诊断/轨迹哈希、审核包与 fixture 哈希、判读、合成分支完整状态/转换及源码哈希。`verify` 重新检查原诊断、重算判读并回放所有边界，然后与保存结果比较。原运行费用不重复计入，人工时间和本次离线耗时未测量时保持 unknown。
