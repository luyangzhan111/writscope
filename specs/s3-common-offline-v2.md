# S3 v2 离线同轮契约

日期：2026-10-26。入口为 [s3_common_offline_v2](../scripts/s3_common_offline_v2.py)，单轨内核为 [s3_scripted_trajectory_v2](../scripts/s3_scripted_trajectory_v2.py)。两者仅执行脚本，无密钥、真实provider、付费命令或标签评分入口。

## 轨迹与版本

内核从原M3p脚本轨迹另立版本，采用 [interaction_quote_v2](interaction-quote-v2.md) 的请求构造与解析、v2提示词、独立配置哈希。保留原来源、范围、原子批次、回查限额、预算模拟及终点 `source_quote_v1` 校验；原v1文件不改，也不在全局临时替换其解析函数。

同轮固定三历史、三方法、R=1，采用原固定轮转顺序。两基线提示词/公开输入不变，每个增量轨从空状态开始，最多五提取、两续答、一终点；每个基线最多一尝试，全组最多30次脚本尝试。任何任务故障终止后续任务，保留九行及not_run状态。

## 输入与输出

输入只来自固定公开包、公开合成脚本和方法提示词。脚本在执行前由可信演练入口选择，不读取参考标签或原真实响应，不根据模型成绩选路径。profile明确绑定脚本hash，不能把某次人工修正伪装成真实重试。

`plan.json`绑定profile、九任务顺序/首次请求/脚本hash、公开输入/权限、模型序列化配置、提示词、内核/契约/范围组件与环境锁hash。模型名称只表示离线请求的序列化参数，未验证后端可用性。

每个job保存请求、脚本响应、合成用量和结果；增量job另保存状态、任务背景、转换、回查、模拟账本及可选终点。根summary保留九任务、首次故障和四阶段汇总；`metrics=null`、`actual_model_calls=0`、实际用量和付费预算为空。

使用标注为offline synthetic的模拟单价与额度，只为验证提取/回查续答/终点/基线四阶段账表，不构成真实核价、预算申请或费用估算。缺失合成用量仍记unknown，失败不删除模拟预留。

## 保存后复验

verify从当前固定公开来源重建plan和脚本。基线重新运行ScriptedMock并比较逐次请求/响应；增量按v2内核重新执行并比较状态、背景、回查、终点和账本，排除不可重现的计时字段。根汇总/报告与文件hash再校验；同时重写文件hash不能掩盖与固定来源不符的数据。

脚本回查一律为 `offline_transport_only`，无回查脚本也不能冒充真实 `not_exercised`。终点有效仅表示脚本契约通过，不能报告模型准确率、方法提升或成本优势。真实v2入口、价格、授权与模型验证均未实现，旧已用授权不得复用。
