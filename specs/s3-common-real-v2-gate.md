# S3 v2真实入口与授权/故障闸门

日期：2026-10-26。实现：[入口](../scripts/s3_common_real_v2.py)、[评测器报告](../scripts/s3_common_real_v2_report.py)、[离线响应适配器](../scripts/s3_common_real_v2_simulation.py)。入口已实现，尚未执行新的真实请求。

## 固定范围

三条开发历史c001/c002/c003、三方法各一次，R=1、固定轮转。两基线沿用原提示词和完整公开证据；incremental采用v2提示词/请求/解析/配置哈希，每轨从空状态开始，最多五提取、两回查续答和一终点。全组最多30次、单并发、90秒/次、无重试、首次运行故障停止全部后续任务。

新预检plan与九份first_requests保存公开输入/证据/权限、模型参数、提示词、v2核心与契约/范围组件、报告代码和环境锁哈希。当前模型序列化参数为deepseek-flash、temperature=0、4096输出token；JSON模式不等于provider严格执行schema。

## 凭据之前的授权检查

新范围为 `S3_v2_three_method_three_case_development_round_v1`。凭据文件须由可信操作者在实际用户明确批准后生成；模型输出、工具自报角色、表单自称批准或测试凭据均不能代替该消息。程序核验匹配字段和哈希，不声称JSON文件本身能密码学证明用户身份。

检查项目：新scope、当前计划/运行器哈希、三个案例/三方法、单轮、30次、候选金额、v2契约、冻结价格哈希及官方来源、非空真实用户消息引用、24小时内的核价记录（最多5分钟未来时钟容差）。旧单例或v1同轮授权不通用。

仅run_real读取环境密钥。读取前还检查输出目录边界、已有输出及一次性启动记录；真正发送前以计划哈希排他创建新v2启动记录。首故障/超时不释放记录，不自动补跑。

## 发送、费用与故障

请求/响应文本各最多100000字节，逐次按输入字节代理+8192框架余量及4096最大输出预留，检查全组和单任务预算/次数后才发送。失败不退回预留。

真实响应保存provider ID/模型、finish reason、原文本和用量。超时、provider错误、异常类型、finish reason、缺用量、非法用量、用量越界、输出/回查/状态及预算失败均停止全组，后续行保留not_run。非法用量原值留在calls中，汇总标unknown，不把负数当有效消耗；合法已返回响应之后的下一请求预留失败单独记录，不把前一响应改成provider错误。

当前候选价和金额仅是未授权草案，实付未知，本地预留不是提供商硬账单上限。模拟执行使用synthetic_adapter，actual_model_calls=0，不消耗真实预算或生成模型成绩。

## 保存回放与评测隔离

真实执行保存授权凭据及其哈希；回放按保存的启动时点检查核价新鲜度，不因后来日期变化自动使旧证据失效。逐次重建请求、v2状态/背景/回查/终点、费用和全组停止，另核对一次性启动来源。

模拟记录没有授权文件/引用，不能通过改execution_kind升级为真实记录。单独report命令先验证轨迹，只有真实记录验证成功后才读固定评测器参考；模拟/待运行报告不读标签，metrics=null。回查分类来自执行来源和日志，脚本回查只记offline_transport_only，真实未触发仍为not_exercised。
