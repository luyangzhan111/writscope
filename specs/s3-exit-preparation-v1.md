# S3 独立审核与回查离线准备契约 v1

日期：2026-10-25。两个入口分别从固定公开包构造阅读材料或请求，提示词和源码/锁文件用于指令及来源绑定，不读取彼此产物或凭据。审核包仅保存首例规格的字节哈希，不复制规格中的作者答案；它们不提供付费执行命令。

## 独立审核包

[review_pack_v1](../scripts/s3_independent_review_pack.py)验证三例前四事件和公开证据相同后，生成四份共同前缀视图、三份 e005 分支视图、来源清单、说明和空白响应模板。视图内嵌原始公开事件、工件登记表及工件内容；不附作者状态、标签、语义判读或预期授权结论。七个审核单元对应十五个案例前缀位置，不增加独立样本数。

`reviewer_response.template.json` 的状态、三轴、理由、来源和审核者信息均为空；`reviewer_response.json` 为可填写副本。来源清单、视图、说明及模板列入冻结哈希，可填写副本不在冻结集合内。`verify` 从公开包重建冻结内容，再比较文件哈希和对象；即使篡改者同时重写清单哈希，改变前缀仍会被拒绝。

表单自报身份、独立性或完成状态不构成可信证明。填写副本变化不使包状态自动从 `prepared_not_reviewed` 升级，`response_assessed` 保持 false；采用审核前另行核对真实审核者来源、既往参与和答案暴露情况，再组织分歧处理。阶段目录和先填共同前缀的操作要求不是访问控制，不能声称程序证明了盲审。

## 真实回查的离线预检草案

[lookup_offline_preflight_v1](../scripts/s3_lookup_offline_preflight.py)以现有 c003 公开包和未改变的交互/终点提示词准备请求。候选模型为现有配置 `deepseek-flash`；本步不核对当前模型可用性或官方价格。三方法的共同公开证据哈希相同，逐事件请求保持完整当前可见原文前缀，不注入独立审核材料或人工正确状态。

`plan.json` 固定草案 `draft_unapproved`、`paid_run_ready=false`、模型/提示词/输入/代码/环境锁哈希，以及以下上限：

- 五次逐事件初始提取、至多两次回查续答、一次终点，最多八次 provider 尝试；本地回查最多两次，每次最多两个事件。
- 单并发、90 秒、无重试，每次最多 4096 输出 token，请求和响应各最多 100000 字节，首次失败停止。
- 每次真实发送前预留，已发生失败不退回本地预留；所有提取、续答、终点及失败均入账。

当前价格、价格核对日期、人民币上限、最坏货币预留、新授权和真实入口绑定均为 null。计划哈希为加入 `plan_sha256` 字段前的规范哈希；旧价格/预算/授权不沿用。本入口不能执行该计划，实际运行须另有接受此新计划的版本化真实入口和精确范围授权。

## 接线演练与结果分类

离线脚本仅用 no_change 提案产生传输测试状态，明确不当作正确提取。六种场景覆盖不回查、一次/两次回查、未来/未知事件及回查额度耗尽；成功分支只生成终点待请求，没有终点预测。回查原文来自可信前缀；模型可见的 elapsed_ms 按现有运行器固定为零，不作真实方法耗时。

结果分类只接受未来运行器持有的真实来源与触发策略、计数和有效性字段，不能采信模型自报：

| 条件 | 分类 |
| --- | --- |
| 离线脚本 | offline_transport_only |
| 真实模型但提示强制触发 | prompted_transport_control_only |
| 真实模型自行选择，完成且没有请求回查 | not_exercised |
| 自行选择的真实请求、原文返回、续答接受和有效终点全部具备 | lookup_branch_exercised |
| 失败或缺有效终点 | failed_or_incomplete_preserved |
| 回查链证据数量不完整 | incomplete_lookup_evidence |

分类函数不是授权闸门；假设输入的单元测试不是一次真实运行。完成但未触发回查不擅自补跑；强制触发不能升级成自主证据。

准备记录保存请求字节哈希及源码来源，`verify` 从公开输入重新生成全部文件和六类路径。改写授权标志、计划或请求，即使同步重写文件哈希也不能通过重建比较。人工状态实验、独立审核完成与 S3 全项退出均不由本预检推定。
